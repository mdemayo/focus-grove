# Focus Grove

Create a modern, minimalist, and accessible productivity web app designed primarily for university students with ADHD.

Use a calm visual design with clear navigation, minimal visual clutter, and an intuitive conversational interface.

Include a dashboard and an AI assistant chat.

For now, create only the frontend with mock data. We will connect an external Google ADK backend later.
